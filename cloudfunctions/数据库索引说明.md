# 微信云开发数据库索引说明

在微信开发者工具 → 云开发控制台 → 数据库 中按下列要求为四个集合添加索引。集合权限一律设为**仅管理端可读写**，小程序端禁止直接读写。

## groups（共享清单）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_publicId | `publicId` | 是 |
| idx_status | `status` | 否 |

## members（成员关系）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| pk | `_id`（主键，即 sha256(groupId:openId)） | 是 |
| idx_group_user | `groupId` + `userOpenId` | 是 |
| idx_group_status | `groupId` + `status` | 否 |
| idx_user_status_updated | `userOpenId` + `status` + `updatedAt`（desc） | 否 |
| idx_group_status_joined | `groupId` + `status` + `joinedAt`（asc） | 否 |

## invites（邀请记录）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_token | `tokenHash` | 是 |
| idx_group_status | `groupId` + `status` | 否 |
| idx_short_status | `shortCode` + `status` | 否 |

## shops（店铺）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_group_updated | `groupId` + `updatedAt`（desc）+ `_id`（desc） | 否 |
| idx_group_category | `groupId` + `category` + `updatedAt`（desc）+ `_id`（desc） | 否 |
| idx_group_request | `groupId` + `requestId` | 否 |
| idx_group_creator | `groupId` + `createdByOpenId` | 否 |

> `requestId` 用于新增店铺的重复请求查询。当前索引为非唯一索引，可以加速幂等检查，但不能单独保证并发请求不会产生重复数据。

> `idx_group_creator` 用于成员修改自己的名称时，同步更新该清单中本人历史店铺的署名。

> 上述两个 shops 索引用于覆盖列表的排序与游标分页。如控制台已有旧版同名索引，请按新字段顺序重建，避免保留功能重叠的索引。
