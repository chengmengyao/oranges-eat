# 微信云开发数据库索引说明

在微信开发者工具 → 云开发控制台 → 数据库 中按下列要求为八个集合添加索引。集合权限一律设为**仅管理端可读写**，小程序端禁止直接读写。

## groups（共享清单）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_publicId | `publicId` | 是 |
| idx_status | `status` | 否 |

## members（成员关系）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| pk | `_id`（主键，即 sha256(groupId:openId)） | 是 |
| idx_group_user | `groupId` + `userOpenId` | 是 |
| idx_group_status | `groupId` + `status` | 否 |
| idx_user_status_updated | `userOpenId` + `status` + `updatedAt`（desc） | 否 |
| idx_group_status_joined | `groupId` + `status` + `joinedAt`（asc） | 否 |

## invites（邀请记录）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_token | `tokenHash` | 是 |
| idx_group_status | `groupId` + `status` | 否 |
| idx_short_status | `shortCode` + `status` | 否 |

## shops（店铺）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_group_updated | `groupId` + `updatedAt`（desc）+ `_id`（desc） | 否 |
| idx_group_category | `groupId` + `category` + `updatedAt`（desc）+ `_id`（desc） | 否 |
| idx_group_request | `groupId` + `requestId` | 否 |
| idx_group_creator | `groupId` + `createdByOpenId` | 否 |
| idx_group_folder_updated | `groupId` + `folderId` + `updatedAt`（desc）+ `_id`（desc） | 否 |
| idx_city_group_updated | `cityCode` + `groupId` + `updatedAt`（desc） | 否 |

## folders（城市子清单）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_group_sort | `groupId` + `sortOrder`（asc） | 否 |
| idx_group_name | `groupId` + `name` | 否 |
| idx_group_city | `groupId` + `cityCode` | 否 |

## cityShops（不归属清单的城市店铺）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_owner_city_updated | `ownerOpenId` + `cityCode` + `updatedAt`（desc） | 否 |
| idx_owner_request | `ownerOpenId` + `requestId` | 否 |

## cityShares（城市店铺分享）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_token_status | `tokenHash` + `status` | 否 |

## cityShareAccepts（城市分享创建的共享清单）

| 索引 | 字段 | 唯一 |
| --- | --- | --- |
| idx_share_recipient_status | `shareId` + `recipientOpenId` + `status` | 否 |

> `requestId` 用于新增店铺的重复请求查询。当前索引为非唯一索引，可以加速幂等检查，但不能单独保证并发请求不会产生重复数据。

> `idx_group_creator` 用于成员修改自己的名称时，同步更新该清单中本人历史店铺的署名。

> `idx_group_folder_updated` 用于按城市子清单筛选店铺时覆盖列表排序与游标分页。如控制台已有旧版同名索引，请按新字段顺序重建，避免保留功能重叠的索引。

> 城市视图会合并当前 OpenID 已加入清单中的店铺，以及当前用户自己添加的 `cityShops`。新清单店铺会在 `folders` 与 `shops` 中冗余写入规范化 `cityCode` / `cityName`；历史数据无需立即迁移，云函数会从旧城市子清单名称兼容生成城市标识。`idx_city_group_updated` 和 `idx_group_city` 为按城市查询预留，建议随本次版本一并创建。

> `cityShops` 保存用户主动添加、但不归属任何清单的城市店铺；`cityShares` 保存 30 天有效的只读分享链接。城市店铺分享不会授予他人编辑或删除权限。

> 扫描城市店铺二维码后会创建一份新的共享清单：分享者是创建者，扫码者是成员。扫码者可以新增和编辑自己添加的店铺，但不能删除店铺。
