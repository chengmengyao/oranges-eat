二、数据模型

type Category = 'restaurant' | 'cake' | 'milktea';

interface Shop {
  _id?: string;
  name: string;        // 店铺名称
  category: Category;  // 分类：饭店 / 蛋糕店 / 奶茶店
  latitude: number;    // 纬度 (gcj02)
  longitude: number;   // 经度 (gcj02)
  address: string;     // 地址
  remark?: string;     // 备注
  createTime: number;  // 创建时间戳
}

三、前置准备（橙子酱待办清单）

  1. 正式 AppID：云开发 + 定位接口需正式小程序（测试号无法开通云开发）
  2. 开通云开发：微信开发者工具 → 云开发 → 创建环境 → 复制环境 ID（实现时填入 src/config/env.ts）
  3. 建集合：云开发控制台 → 数据库 → 创建 shops 集合，权限「所有用户可读写」（演示期）
  4. 开定位权限：小程序后台 → 开发管理 → 接口设置 → 开通 getLocation、chooseLocation
  5. 隐私指引：小程序后台配置「用户隐私保护指引」，声明位置信息用途

七、功能设计

🗺️ 地图页 pages/index（首页 tab）

  • 全屏 <map>：show-location 显示当前位置蓝点，markers 打点全部店铺（按分类选 PNG 图标，宽高约 44px），include-points 自动缩放包含所有点
  • 进入时 getLocation(gcj02) 取定位；首次启动若集合为空，以当前位置为中心自动写入 7 家示例店铺（3 饭店 / 2 蛋糕 / 2 奶茶，偏移 200~1500m）便于演示
  • 右下角悬浮「离我最近」按钮 → 底部 wd-popup 弹出店铺列表，按距离升序，显示「xx 米 / x.xx 公里」+ 分类标签
  • 点击 marker → 弹出店铺小卡片（名称 / 地址 / 备注）+「导航前往」（openLocation）
  • 顶部叠加分类图例（三色小图标）

🍰 美食页 pages/food（tab）

  • 顶部 wd-tabs 筛选：全部 / 饭店 / 蛋糕店 / 奶茶店
  • 店铺列表：分类图标 + 名称 + 地址 + 距我距离（已授权定位时显示）
  • 右下 FAB「新增店铺」→ 底部 wd-popup 表单：名称、分类（radio）、「在地图上选点」按钮（wx.chooseLocation 自动回填经纬度+地址，可改）、备注
  • 每条目「编辑 / 删除」操作，删除用 wd-dialog 二次确认，成功 wd-toast
  • 增删改查直连云开发 shops 集合，切回地图页自动刷新打点

☁️ 云数据层

db.collection('shops') 的 add / doc.update / doc.remove / get / count；wx.cloud.init({ env }) 在 App.vue onLaunch 守卫执行（非微信端跳过），环境未配置时 toast 提示。

八、实施步骤

  1. degit 拉取 vite-ts 模板到当前目录 → 安装依赖（npm）+ sass@^1.98 + @wot-ui/ui + sharp
  2. 配置：pages.json（easycom / tabBar / permission / 导航栏）、manifest.json（appid / requiredPrivateInfos）、vite.config.ts（sass modern-compiler 防警告）、tsconfig（wot 全局类型）
  3. 运行 gen-icons.mjs 生成 PNG
  4. 写主题（uni.scss / theme.scss / App.vue）
  5. 写数据层 + 工具（types / cloud / shop / geo / location）
  6. 写地图页、美食页
  7. 验证：npm run type-check + npm run build:mp-weixin 构建通过

九、验证方式

  • 命令验证：type-check 零错误、mp-weixin 构建成功
  • 开发者工具 / 真机验证（橙子酱配合）：导入 dist/dev/mp-weixin → 填入云环境 ID → 验证定位授权、打点渲染、离我最近列表、增删改查闭环

十、风险与注意

  • 云开发、chooseLocation 必须在正式 AppID + 已开通对应权限下才能跑通（见前置清单）
  • 集合权限「所有用户可读写」仅是演示配置，正式发布建议改为云函数写入 + 权限规则收紧
  • wd-toast / wd-dialog 等按 Wot 规范需在页面显式放置（不支持全局挂载）
  • 地图打点图标为彩色图标直接上地图，如需白色圆底徽标样式可后续增强
